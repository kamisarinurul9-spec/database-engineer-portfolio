# TiDB Distributed Cluster

## Overview
This project demonstrates TiDB cluster setup for distributed SQL processing.

## Architecture
- PD (Placement Driver)
- TiKV (Storage)
- TiDB (SQL Layer)
- TiProxy (Load Balance)

## Features
- Horizontal scaling
- MySQL compatibility
- Strong consistency

## Tech Stack
- TiDB
- Docker

## Results
- Distributed transaction support
- High availability system

## Lessons Learned
- Separation of compute & storage
- Great for hybrid workloads (HTAP)
