# Backup & Disaster Recovery Strategy

## Overview
This project demonstrates backup and disaster recovery strategies for production databases.

## Features
- Full backup
- Incremental backup
- Restore testing

## Tools
- mysqldump / xtrabackup
- cron jobs
- mongodump
- TiDB Data Migration / Change Data Capture (CDC)

## Results
- Reduced risk of data loss
- Improved recovery time

## Lessons Learned
- Backup without restore test = useless
- Automation is critical
