# MySQL Replication High Availability

## Overview
This project demonstrates MySQL master-slave replication setup for high availability and read scalability.

## Architecture
Primary → Replica

## Features
- Master-Slave replication
- Read scaling
- Query optimization

## Tech Stack
- Percona MySQL 8
- Docker
- ProxySQL

## Results
- Improved read performance
- Enabled high availability setup

## Lessons Learned
- Replication improves scalability
- Indexing is critical for performance
